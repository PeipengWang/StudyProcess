# Agent四大组件-规划、工具、记忆

## 规划

当前agent只能做某一行业或任务领域的落地，不能做泛用性的

### 子任务拆解

思维链、思维树和思维术决策

### 反思与改进

ReAct框架：推理与行动的协同

## 工具

将大模型由静态转化为动态的能力。例如读取数据库、调用软件进行图像识别

安全可控

不要冗余

## 记忆

划分短期记忆与长期记忆，二者协同工作，支撑其认知与行动能力

长期记忆：知识库中--》外部向量数据库

短期记忆：上下文中

设计建议：分层管理、按需检索、隐私与安全、可遗忘性

## 框架

Plan-and-Execute：分阶段处理复杂任务的智能体架构模式

全局规划-分布执行-动态优化-闭环验证

ReAct

Self-Ask：复杂任务拆解为一个个简单任务，并通过自问自答的方式逐步求解
